============================================================
  PRŮVODCE DECHEM - OFFLINE APLIKACE PRO WINDOWS
============================================================

Tato aplikace je 100% soběstačná a ke svému běhu NEPOTŘEBUJE
žádné připojení k internetu. Všechny zvuky, duhový kruh, 
meditační hudba i časovače fungují zcela offline.

JAK APLIKACI SPUSTIT:
---------------------
1. Rozbalte stažený archiv .ZIP (pravým tlačítkem myši -> Extrahovat vše).
2. Pro spuštění v samostatném okně bez rušivých prvků klikněte na:
   -> Spustit-jako-aplikace-Edge.bat (nebo Spustit-jako-aplikace-Chrome.bat)
3. Nebo jednoduše dvakrát klikněte na:
   -> Spustit-ve-Windows.bat (případně přímo na soubor Pruvodce-dechem.html)

TIPY:
- Soubor nebo zástupce si můžete umístit přímo na plochu Windows.
- Aplikaci můžete mít uloženou i na USB flash disku a spustit ji
  na jakémkoliv počítači s Windows bez nutnosti instalace či internetu.
